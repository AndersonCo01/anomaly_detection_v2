# Steel Surface Defect Classification

## Final Project

This project builds a Convolutional Neural Network (CNN) capable of classifying defects on steel surfaces using PyTorch.

---

### Project Objectives

- Build a CNN classifier
- Train using PyTorch
- Evaluate model performance
- Analyze predictions
- Document the entire pipeline
